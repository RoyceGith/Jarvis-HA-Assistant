ZBRANO v0.12.65 adds read-only Grinder Deep Monitoring over MQTT. It keeps a bounded 60-second telemetry flight recorder, detects heartbeat loss and new boot IDs, stores reboot incidents with pre-failure evidence, and exposes diagnostic status and incidents through read-only chat tools and APIs. ZBRANO never publishes a grinder command; the ESP32-S3 remains the machine-control and safety authority.
