ZBRANO v0.12.56 restricts Gmail MCP OAuth to the exact `gmail.readonly` and `gmail.compose` allowlist. Broader or incomplete grants are rejected and revoked before storage, previously stored noncompliant Gmail tokens are quarantined during startup, incremental scope inheritance is disabled, and Google now presents an account chooser on every connection. Installed Plugins safely displays the connected Gmail address and granted scope names without exposing tokens or secrets. The Home Assistant Ingress retry now replaces its transient 401 page with a concise authorization-progress screen.
