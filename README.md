ZBRANO v0.12.54 enables the curated Gmail MCP connector through a pre-registered Google Web OAuth client configured securely in Home Assistant add-on settings. The Gmail catalog card provides the exact ingress callback URL, changes to Connect with Google once credentials are configured, requests offline refresh access, and keeps discovered Gmail write tools approval-gated. Device power commands such as turn on, turn off, and switch now take the Home Assistant fast path before repository, plugin, memory, or web tools, including while Developer Mode is left enabled. Multi-round Home Assistant entity lookup and control now share one activity indicator and elapsed timer instead of producing duplicate Reading Home Assistant entries. Shared Files now uses a stable visible-file inventory for activity detection, reliably clears its orange dot when viewed, and no longer displays the SYS/ZBRANO_WORKSHOP panel label. Per-chat voice playback, low-latency speech, semantic activity indicators, and New Chat activity reset remain enabled.
