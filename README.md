Jarvis Workshop Assistant v0.12.9 adds secure browser OAuth for compatible remote MCP plugins. Cloudflare and Canva now provide Connect actions that perform protected-resource discovery, dynamic client registration, PKCE authorization, callback validation, token refresh, reauthorization, and sign-out. OAuth plugins install enabled after consent; read-only tools run normally while write-capable tools remain approval-gated. Google Workspace continues to show configuration guidance because Google requires an owner-created Cloud project and OAuth client.
