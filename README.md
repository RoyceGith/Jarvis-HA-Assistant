ZBRANO v0.12.26 adds native OpenAI Web Search to normal Chat with Auto, Search Web, and Web Off modes. Search activity is visible, consulted sources are extracted and persisted, citations render as safe clickable links, and Settings controls search availability and context size. Developer Mode remains isolated from public search. This release also repairs local Playwright MCP initialization with an explicit localhost-only host allowlist and bounded Chromium, process, HTTP, and startup-log diagnostics.
