ZBRANO v0.12.36 routes Playwright inspection only to reported visual DOM, layout, rendering, browser-console, or browser-network defects. Backend APIs, MCP approval payloads, versions, repository source, and non-visual tool execution remain on targeted diagnostics and repository inspection. Playwright now has a 30-second end-to-end deadline, a 35-second outer safety limit, and step-specific timeout evidence with bounded startup-log context. v0.12.35 plugin approvals remain enabled.
