ZBRANO v0.12.16 adds a built-in Playwright MCP browser inspector for Developer Mode. It runs headless Chromium locally on the Home Assistant add-on, is restricted to ZBRANO's own local UI, and returns bounded DOM, console-error, and network-request evidence. It may switch among a fixed set of ZBRANO navigation tabs, but cannot use arbitrary selectors, operate feature controls, type, upload, or browse external sites. The Plugins screen shows its live health at the top, and diagnostics now verify the local MCP service and its required tools.
