ZBRANO v0.12.57 adds Gmail Direct, a built-in least-privilege connector using the standard Gmail REST API instead of Google’s gated Workspace Developer Preview MCP tool server. It provides bounded mail search, label listing, thread reading, and approval-gated creation of unsent drafts. It exposes no send, delete, trash, attachment-download, or label-mutation operation, and treats all email content as untrusted data that cannot direct tool execution. Existing compliant Google OAuth connections are migrated automatically while the exact `gmail.readonly` and `gmail.compose` scope allowlist remains enforced.
