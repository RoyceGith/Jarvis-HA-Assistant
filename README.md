ZBRANO v0.12.30 places the Web Auto, On, and Off selector and enabled-plugin indicators inside a dedicated stack directly beneath the Chat textarea. Official SVGs for Playwright, GitHub, Cloudflare, Gmail, Google Drive, Google Calendar, and Google Chat are bundled locally; unavailable brands use reliable letter fallbacks, and the generated application makes no runtime Simple Icons CDN requests. Synthetic diagnostics conversations are excluded from persistence and the user-visible chat list, and previously leaked diagnostic sessions are purged. Frontend cache prevention remains active.
