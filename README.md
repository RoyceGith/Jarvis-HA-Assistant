Jarvis Workshop Assistant v0.12.13 aligns the streamlined Workshop Memory workflow with Workshop Memory v0.1.28. A normal `approve` authorizes one exact write, while `approve task` authorizes Workshop Memory writes in that chat for 15 minutes. Large note bodies remain private inside pending tool calls; approval prompts show only their destination, mode, title, character count, and line count. The companion server identifies read-only tools correctly and creates missing folders plus a generic Markdown note in one write.
